# ticketBar — La Patrona Disco Club

## Descripción del módulo
**ticketBar** es un sistema web orientado a la gestión y reserva de mesas y espacios para **La Patrona Disco Club**. El módulo permite consultar eventos disponibles, revisar la disponibilidad en el plano de mesas, registrar los datos del cliente y generar un pase digital con código QR sin cobros en línea (tarifa $0 COP). También cuenta con acceso administrativo para supervisar las reservas.

## Tecnologías utilizadas
* **Frontend:** HTML5, CSS3 y JavaScript.
* **Entorno de ejecución:** Navegador web y servidor local (Live Server en Visual Studio Code).
* **Control de versiones:** Git y GitHub.

## Instrucciones para ejecutar el módulo
1. Descarga o abre la carpeta del proyecto en **Visual Studio Code**.
2. Abre `index.html` con **Live Server** o directamente en el navegador web.
3. Para ingresar al panel de administración, abre `login.html` desde la opción **Acceso Admin**.
